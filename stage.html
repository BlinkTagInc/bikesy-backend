How distances and elevation are compared

Mileage is measured along each returned route shape with the same method, not the servers’ reported totals. Deltas are New minus Old. Map detail and endpoint snapping can still differ.

Both elevation profiles use the same locked Skadi terrain tiles, sampled every 30 meters. Up/down adds only positive/negative height changes. This measures terrain, not surveyed riding elevation: tunnels, bridges, ferries and small climbs can be misleading. Elevation deltas appear only when both common-terrain profiles are complete. The engines’ original elevation profiles use different or unverified sampling and are not used for these deltas.

Old routes come from the existing public Bikesy API and its historical routing data. They are comparisons, not a confirmation of current access or conditions. A failed old route does not hide the new route.
